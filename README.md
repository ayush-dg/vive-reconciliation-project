# VIVE Statement Reconciliation

Automated AP reconciliation for VIVE (auto body shops) — reconciles vendor PDF statements
against NetSuite (AP bills) and CCC ONE (repair-order data) on Microsoft Fabric.

Built under the DataGrokr DG-Forge PBVI methodology (`pbvi_core.md` v4.9).

- **`PROJECT_MANIFEST.md`** — file registry and current project status. Read this first.
- **`docs/Claude.md`** — the execution contract. Governs everything CC does in this repo.
- **`docs/ARCHITECTURE.md`** — key design decisions for this bounded first build.
